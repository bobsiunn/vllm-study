   821	### 세 문장 요약
   822	
   823	- **얼마나 계산할지**는 scheduler token accounting이 결정합니다.
   824	    - 새 request에서는 local prefix hit과 external KV hit이 computed token으로 합쳐집니다.
   825	- **KV를 어떻게 확보할지**는 connector lifecycle이 결정합니다.
   826	    - local reuse, async remote load, layer-wise save, invalid block recovery는 다른 경로입니다.
   827	- **instance 사이에서 무엇이 이동하는지**는 control plane/data plane 분리로 봅니다.
   828	    - `kv_transfer_params`는 proxy/HTTP로 이동하는 metadata.
   829	    - 실제 KV bytes는 worker-side connector transport로 이동.
